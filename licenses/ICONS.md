# Icon and mark sourcing

This package uses simple typographic monograms (GH, in, IG, X, M, Bē, SO, Q, P, f) and custom SVG geometry rather than embedding third-party brand icon paths. They are presentation labels, not official logo reproductions. Official profile links are listed in `README.md`.

No external icon font, CDN, image URL, or remote SVG request is used by the five profile SVGs.
