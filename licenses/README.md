# Licences

- `INTER-LICENSE.txt`: Inter typeface licensing information supplied by the installed Inter font package (SIL Open Font License 1.1 and Apache-2.0 notices).
- `GO-FONTS-LICENSE.txt`: licensing notice for the Go Mono typeface source available in the build environment. Verify the upstream licence for any downstream redistribution if you replace this font.
- `ICONS.md`: documents the monogram/custom geometry approach; no third-party brand paths are embedded.

Font subsets are embedded as base64 WOFF2 in each SVG when subsetting succeeds. The matching subset WOFF2 files are included here for inspection and reproducibility.
